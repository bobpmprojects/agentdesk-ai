# Returns and Refunds

## 30-day return window {#return-window}

Returns and refunds are available within 30 days after delivery.

## Automatic refund limit {#refund-limit}

Verified refunds of $200 or less may be automatically approved. For amounts above
$200, offer store credit instead of a cash refund.

## Duplicate requests {#refund-idempotency}

Repeating the same refund request must not create a second refund.
